Theory of Computation: Thompson's Construction Step-by-Step
Formal Mechanics
1. Basic Symbol (a)

Creates an initial state $s_0$, an accepting state $s_1$, and a single transition $s_0 \xrightarrow{a} s_1$.

2. Concatenation (r₁·r₂)

Connects accepting state of $N(r_1)$ to start state of $N(r_2)$ via an $\epsilon$-transition: $A_1 \xrightarrow{\epsilon} S_2$.

3. Alternation (r₁ | r₂)

Introduces new start $S$ and new accept $A$. Adds $\epsilon$-branches $S \to S_1, S_2$ and $A_1, A_2 \to A$.

4. Kleene Star (r*)

Adds loopback $A_1 \xrightarrow{\epsilon} S_1$, and zero-pass bypass $S \xrightarrow{\epsilon} A$, with $S \xrightarrow{\epsilon} S_1$ and $A_1 \xrightarrow{\epsilon} A$.
