Theory of Computation: Regular Expression Metacharacters Reference
Syntax Guide
Token Name Formal Meaning Example Expression Sample Matches
\d Digit Matches any ASCII numeric digit [0-9] id=\d+ id=123, id=0
\w Word Character Matches alphanumeric character or underscore [a-zA-Z0-9_] user_\w+ user_admin, user_42
\s Whitespace Matches space, tab, newline, carriage return union\s+select union select, union select
* Kleene Star Zero or more repetitions of preceding element (L*) a*b b, ab, aaaaab
+ Positive Closure One or more repetitions of preceding element (L+) 1+ 1, 111 (not empty)
? Optional (0 or 1) Preceding token is optional; matches 0 or 1 time https? http, https
| Alternation / Union Matches either the expression before or after (L1 ∪ L2) admin|root admin, root
() Capturing Group Groups tokens together for precedence or quantified repetition (ab)+ ab, ababab
[] Character Class Matches any single character enclosed in the set [abc] a, b, or c
^ Start of Line Anchor Asserts position at the beginning of the string or line ^admin administrator (at start)
$ End of Line Anchor Asserts position at the end of the string or line passwd$ /etc/passwd (at end)
